# Database migration

Working directory for every command: the repository root.

Connection string for sqlacodegen:

`postgresql+psycopg2://postgres:postgres@localhost:5433/postgres`

## Workflow

1. Create the migration file from the repository root:

```bash
dbmate new "<migration name>"
```

2. Fill in the SQL in the created file under `db/migrations/` (`-- migrate:up` and `-- migrate:down`). Follow the schema conventions below.

3. Stop. Ask the user to apply the migration themselves. Do not continue until the user explicitly confirms that the migration has been applied.

4. Only after that confirmation, run codegen from the repository root:

```bash
uv run python -m sqlacodegen "postgresql+psycopg2://postgres:postgres@localhost:5433/postgres" --outfile app/models.py
```

## Schema conventions

- Name every table in the singular: `user`, not `users`.
- Add a default on every column that can have one. A timestamp such as `created_at` must default to `now()`:

```sql
created_at TIMESTAMP NOT NULL DEFAULT now()
```

## Prohibitions

- The agent must not apply migrations on its own. Do not run `dbmate up`, `dbmate migrate`, `dbmate down`, `dbmate rollback`, and do not execute SQL against the database. Only the user applies the migration.
- The agent must not modify `app/models.py`. Do not edit this file by hand. The only allowed way to update it is the sqlacodegen command from step 4, and only after the user confirms the migration was applied.
